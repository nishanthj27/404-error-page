# 404 Error Page

An animated, space-themed 404 error page built as a single static HTML file for Chennai Institute of Technology, Chennai.

## Features

- Animated starfield background
- Astronaut illustration with floating planets
- Responsive layout for desktop and mobile
- Hash-based navigation between multiple themed sections
- Contact form mockup with simple client-side interaction
- Lightweight and dependency-free beyond Google Fonts

## Project Structure

- `index.html` - the entire page markup, styling, and behavior

## How to Run

1. Open `index.html` in a web browser.
2. Or use a local server if you prefer a development workflow.

### Optional Local Server

If you have Python installed, run this from the project folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Notes

- The page uses external Google Fonts, so an internet connection is required for the intended typography.
- The contact form is decorative and shows an alert instead of sending data anywhere.
